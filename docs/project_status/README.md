# 产品状态索引

本目录是在真实渠道发布后的受管记录阶段、重要阻断、跨会话交接或用户要求时，当前阶段、已完成事项、待确认项和下一步的唯一正文来源。候选构建、E2E、完整验收和就绪复核不写本目录，日常开发也不逐次更新状态快照。

普通缺陷修复、纯重构、格式整理、测试补强和内部清理的开始或完成本身不更新 Product Status；若同一任务形成重要阻断或交接，只记录该独立状态事件。真实渠道发布成功后才在后续受管 feature 生命周期记录发布状态；`pending`/`accepted` 候选不触发 tracked 状态。

## 写入规则

- 文件名固定为 `YYYYMMDD_product_status.md`，日期使用状态更新所在时区的自然日。
- 同一天只维护一份产品状态；状态变化后持续整理并更新当日文件，不得为同一天新建第二份。
- 新自然日首次写入时，必须读取前一份产品状态，将仍有效状态与当日变化综合重写为一份完整的当前状态；不得复制流水账或只写增量。
- 日期文件是当日完整有效快照；只保留日期最新的文件，被后续日期完全取代的旧日期文件随即删除，历史由 Git 版本控制承担。当前状态始终取日期最新的文件。
