# 测试最终产物 E2E

通过真实客户端或宿主使用的同一可见交互路径，验证已批准范围内的场景。本工程只提供 Go 后端服务能力：接口固定为 HTTP API，不存在 CLI、TUI、MCP 或 GUI。

## 工作流程

1. 读取已批准成功标准、当前构建的 E2E 选择、`docs/VERIFICATION.md` 及适用接口 Skill。要求当前构建选择为 `enabled`，或存在已批准产品/渠道的 `required` 规则；`e2e_hint` 不能替代当前构建选择。
2. 要求 `$go-verify-delivery` 已定位与源码提交、构建身份和 manifest 绑定的完整真实最终产物。拒绝源码直接运行（`go run`）、开发模式预览、模拟后端、脚手架、占位内容或推测路径；没有 Work Plan 不阻断 E2E。
3. 根据批准标准定义有边界的核心成功路径和最高风险失败路径，说明前置条件、隔离且可逆的数据、预期观测、清理和超时。测试数据必须使用一次性数据库与一次性端口，禁止指向真实环境或生产数据。
4. 启动真实候选制品，按已确认的 `interfaces` 事实逐项验证。每项请求前后都检查全新状态；不得以单个成功请求或单条日志作为证据。
5. 验证状态、输出、持久化数据或错误呈现。除非另获授权，必须在凭据、支付、生产、发布或不可逆操作前停止。
6. 在 runner 临时位置形成结构化的产物/版本、源码提交、平台、步骤、预期/观测结果、适用日志、关闭、清理和通过/失败结果，遮盖敏感信息与不必要个人路径；只把这些结果交回 `$go-verify-delivery` 作为待原子写入的候选证据，不直接逐个改写 release manifest，也不写 tracked Verification。
7. 任何失败、超时、取消或已启用但未运行的场景都拒绝候选并返回 `$go-implement-change` 增加回归测试；修复后重新构建完整候选。最终容器字节变化会使旧 E2E 证据失效；若变化同时影响运行时字节、启动参数、配置、依赖或行为，必须重建并重跑。只有用户要求的活动计划存在时才重开或新增 Todo。
8. 所有场景和清理结束时，对当前 `release/` 重新枚举精确文件集，并重新计算全部最终制品、相邻摘要和 manifest 声明；要求源码提交、构建身份和每项字节与 E2E 准入快照一致。不得只声称“字节变化会使证据失效”而跳过结束复算；任何变化都使本次结果失效并交回 `$go-verify-delivery` 拒绝状态更新，不能把新摘要倒填进旧 manifest。
9. 未实际执行的操作系统、架构、数据库驱动和包格式标记为 `Unverified`；必需人工最终复核仍是独立步骤，Agent 不得代签。

## 接口覆盖

### HTTP API

- **启动与生命周期**：真实制品使用候选内置配置启动，监听地址来自配置而非硬编码；进程接收 `SIGTERM`/中断信号后必须在配置的 `shutdown_timeout` 内完成优雅关闭，退出码为 0，且不再接受新连接。
- **存活与运行信息**：`GET /healthz` 返回 `200` 且正文为 `ok`；`GET /api/v1/system/health-check` 返回单对象形状，`data` 的 `name`/`version`/`env` 与候选身份和 `.harness/version-state.json` 一致。
- **统一响应体**：实际触发单对象、数据集、分页、空结果与失败五种形状，逐项比对字段名与嵌套结构；分页形状必须含 `page.current`/`page.size`/`page.total` 与 `result.model == "data.set"`。
- **中间件行为**：响应必须带 `X-Request-Id`（传入时原样回写，缺失时生成非空值）；`Content-Language` 与 `Vary` 按配置出现；`CORS` 启用时预检请求返回 `204` 且回显允许的来源；`RateLimit` 启用时超限返回统一失败体与稳定错误码。
- **错误契约**：未知路由、不支持方法与非法请求体分别返回可区分的稳定错误码；5xx 响应不得泄漏内部堆栈或文件路径。
- **多语言**：同一失败请求分别携带 `Accept-Language: zh-CN` 与 `en-US` 时，`message` 切换而 `code` 保持不变；回退语言在未知语言下生效。
- **持久化**：任何写路径必须落库并在重启后仍可读；隔离数据库断言表结构与数据内容，测试结束后删除该数据库。

## 完成输出

报告精确产物、候选身份与版本、当前构建选择/硬要求来源、`interfaces` 事实、逐项场景、可观察证据、清理结果、通过项、失败项和未验证范围。不得自行签署人工复核字段。
